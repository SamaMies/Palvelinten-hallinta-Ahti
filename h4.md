# a) Räpylä

Aloitin päivittämällä paketit ``sudo apt update``, sitten asensin "chronyn" komennolla ``sudo apt install -y chrony``. Tarkistin sen käynnissäolon komennolla ``systemctl status chrony`` ja se tulosti "active (running)".
